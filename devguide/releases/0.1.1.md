# Praxis 0.1.1 source qualification

Owner: [Praxis #9](https://github.com/uibcdf/praxis/issues/9). This patch follows the
frozen [0.1.0 milestone](0.1.0.md). Exact source/tag identity, installed-artifact
acceptance, hashes and native CI conclusions are recorded in that issue before
the source tag is published; a configured workflow or a local test alone is not
release acceptance.

## Scope

- [#15](https://github.com/uibcdf/praxis/issues/15): terminal runtime-gate enforcement
  survives a recipe catching its check exception. Failed mandatory checks reject;
  unresolved checks block and unresolved human reviews wait. Advisory findings stay
  advisory. Partial outputs and findings remain inspectable.
- [#16](https://github.com/uibcdf/praxis/issues/16): definition audits distinguish
  a human-review declaration from a missing executable checker. Pending scientific
  review/admission is not fabricated or suppressed.
- [#14](https://github.com/uibcdf/praxis/issues/14): metadata/recipe bounds admit
  ArgDigest 0.17, SMonitor 0.22 and PyUnitWizard 0.29. Current development/latest
  environments pin their public files plus Recorda 0.3.3; legacy build/installed
  lanes preserve floor coverage. See [receiving scope](../LATEST_SUPPORT_RECEIVING.md).
- [#9](https://github.com/uibcdf/praxis/issues/9): current documentation records
  MOLI PR #66's 2026-10-21 merge while preserving original release evidence.

Regression tests exercise failed/unknown/skipped/checker-error runtime findings,
human rejection/waiting, advisory behavior, and human versus executable requirements
in both Capability and Protocol definition audits. Existing diagnostic, quantities,
recording, attribution, benchmark and replay contracts remain part of qualification.

## Acceptance and publication boundary

Before tagging, require an exact-source main workflow with quality, shared candidate
build, installed Conda on Linux x86_64/macOS arm64 × Python 3.11–3.14, the Linux 3.14
wheel, measured main coverage and all eight latest-public-provider cells. Routine
pushes run only one latest cell; a manual exact-head test run supplies the complete
latest matrix. Record component governance for the same source. Retain the original
candidate files and their hashes; never rebuild a file to reuse an old receipt.

The optional real-MolSysMT test may skip where that scientific provider is absent.
Recorda/Ackredit qualification must execute. No hydrogen engine, new scientific
assessment or completed MOLI #28 invocation agreement is implied.

A public source tag is separate from a GitHub Release, Conda upload and archival.
This work does not select package publication. The manual publisher defaults to
read-only readiness; publishing an original qualified file still requires its own
authorization, coordinate/write checks, independent public poststate and clean
public-channel installation. No public PyPI route is planned.
